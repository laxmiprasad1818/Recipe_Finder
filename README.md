# 🍲 Smart Recipe Finder

Smart Recipe Finder is a simple and elegant web application that helps users discover recipes based on the ingredients they already have. With support for diet-based filtering and cooking time constraints, the app ensures users can quickly find meal ideas that match their preferences.

This project integrates the [Spoonacular Recipe API](https://spoonacular.com/food-api) to fetch live recipe data and offers a beginner-friendly frontend development example using **HTML**, **CSS**, and **JavaScript**.

---

## 📌 Features

- 🔐 **Basic Login Page UI**
  - No backend, just a placeholder to simulate user login.
- 🧾 **Ingredient-Based Search**
  - Enter multiple ingredients (e.g., *onion, tomato, chicken*) to fetch matching recipes.
- 🥗 **Diet Filter**
  - Choose between: **Veg**, **Non-Veg**, or **Both**.
- ⏱️ **Cooking Time Filter**
  - Limit recipes by max ready time (15 to 90 minutes).
- 📋 **Recipe Display**
  - Each recipe includes: title, image, preparation time, and a link to the full recipe.
- ⭐ **Featured Recipes**
  - Displays 6 random recipes on page load.
